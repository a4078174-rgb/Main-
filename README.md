# GitHub User Finder

Автор: Артём Чигарев

## Описание

GitHub User Finder – это настольное GUI-приложение для поиска пользователей GitHub.  
Оно использует публичное REST API GitHub (GET /search/users), позволяет добавлять пользователей в избранное и сохраняет список избранного в локальный JSON-файл.

### Возможности
- Поиск пользователей GitHub по логину (поддерживается частичное совпадение).
- Отображение результатов списком с логином и ID пользователя.
- Добавление пользователей в избранное и удаление из него.
- Автоматическое сохранение избранного в favorites.json.
- Простой и интуитивно понятный интерфейс на tkinter.

## Как использовать GitHub API

Приложение отправляет GET-запрос к эндпоинту:  
https://api.github.com/search/users?q={query}&per_page=30

- {query} – строка поиска (логин пользователя).
- per_page=30 – ограничивает количество результатов (максимум 30).
- API возвращает JSON с массивом items, содержащим информацию о пользователях (логин, ID, URL профиля и др.).

Для работы с API не требуется аутентификация, но для больших объёмов запросов GitHub может ограничивать количество запросов с одного IP. Подробнее: [GitHub REST API](https://docs.github.com/ru/rest/search).
